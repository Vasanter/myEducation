# Горячие клавиши PyCharm (Windows/Linux)

> 💡 Все горячие клавиши можно настроить в `File → Settings → Keymap`

---

## 🧭 Навигация и редактирование

| Горячие клавиши | Описание |
|-----------------|-----------|
| `Ctrl + Space` | Базовое автодополнение кода |
| `Ctrl + Shift + Space` | Умное автодополнение (учитывает контекст) |
| `Ctrl + P` | Показать параметры метода (сигнатуру) |
| `Ctrl + Q` | Быстрая документация |
| `Ctrl + F1` | Показать описание ошибки/предупреждения |
| `Ctrl + /` | Закомментировать/раскомментировать строку |
| `Ctrl + Shift + /` | Закомментировать блок кода |
| `Tab` / `Shift + Tab` | Увеличить/уменьшить отступ |
| `Ctrl + Alt + L` | Форматировать код по стандарту |
| `Ctrl + D` | Дублировать текущую строку или выделение |
| `Ctrl + Shift + ↑/↓` | Переместить строку/блок вверх/вниз |
| **`Ctrl + W`** | **Расширить выделение (очень полезно!)** |
| **`Ctrl + Shift + W`** | **Уменьшить выделение** |
| **`Ctrl + Y`** | **Удалить строку** |
| **`Ctrl + X`** | **Вырезать строку (без выделения)** |
| **`Ctrl + ←/→`** | **Перемещение по словам** |
| **`Ctrl + Backspace`** | **Удалить слово** |
| **`Alt + J`** | **Множественное выделение (добавить следующее совпадение)** |
| **`Alt + Shift + J`** | **Отменить последнее выделение** |
| **`Ctrl + Alt + Shift + J`** | **Выделить все совпадения** |

## 📝 Дополнительные советы

### Множественное редактирование:
- **`Alt + J`** — выделить следующее вхождение
- **`Alt + Shift + J`** — отменить последнее выделение
- **`Ctrl + Alt + Shift + J`** — выделить все вхождения
- **Удерживая `Alt`**, кликайте мышью в разных местах для создания нескольких курсоров

### Emmet/Zen Coding (для HTML/CSS):
- Напишите `div.container>ul>li*5` и нажмите `Tab`

### Live Templates (шаблоны кода):
- Напишите `main` и нажмите `Tab` — создастся метод main
- Напишите `fori` и нажмите `Tab` — цикл for

### Полезные настройки:
- `File → Settings → Editor → General → Code Completion` — автодополнение
- `File → Settings → Keymap` — настройка горячих клавиш
- `View → Appearance → Toolbar` — показать/скрыть панель инструментов
