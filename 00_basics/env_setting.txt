"""
ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ (Virtual Environment)
=============================================
Виртуальное окружение — это изолированная среда для Python-проекта,
которая позволяет устанавливать библиотеки локально, не затрагивая
глобальную установку Python и другие проекты.

Зачем нужно:
- Изоляция зависимостей между проектами
- Возможность использовать разные версии библиотек
- Чистота глобального окружения
- Воспроизводимость окружения на других машинах
"""

# ============================================
# 1. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ
# ============================================

# Windows:
python -m venv venv

# macOS / Linux:
python3 -m venv venv

# Создание с определенной версией Python:
py -3.14 -m venv env  # Windows (если установлено несколько версий)
python3.12 -m venv env  # macOS/Linux


# ============================================
# 2. АКТИВАЦИЯ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ
# ============================================

# Windows (Command Prompt):
venv\Scripts\activate

# Windows (PowerShell):
venv\Scripts\Activate.ps1

# macOS / Linux:
source venv/bin/activate

# После активации в начале строки появится (venv)


# ============================================
# 3. ПРОВЕРКА АКТИВАЦИИ
# ============================================

# Проверить, что используется нужный Python:
which python  # macOS/Linux
where python  # Windows

# Проверить установленные пакеты:
pip list


# ============================================
# 4. УСТАНОВКА ПАКЕТОВ В ОКРУЖЕНИЕ
# ============================================

# Устанавливаем пакеты локально в venv:
pip install requests
pip install numpy


# ============================================
# 5. СОХРАНЕНИЕ ЗАВИСИМОСТЕЙ
# ============================================

# Создать файл со списком зависимостей:
pip freeze > requirements.txt

# Установить зависимости из файла (на другой машине):
pip install -r requirements.txt


# ============================================
# 6. ДЕАКТИВАЦИЯ
# ============================================

deactivate  # работает во всех ОС


# ============================================
# 7. ПОЛЕЗНЫЕ СОВЕТЫ
# ============================================

# Добавить venv в .gitignore (если используете Git):
# venv/
# env/
# .venv/

# Использовать разные версии Python:
python3.9 -m venv venv39
python3.11 -m venv venv311
python3.12 -m venv venv312

# Проверить версию Python в venv:
python --version
